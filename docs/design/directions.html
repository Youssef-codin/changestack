Briefing and Review, in Riso

Three directions, all in the Riso colorway, so they differ only in type, density and structure. Each is lustre-clinic #127 (appointment reminders over SMS), drawn four times: Briefing and Review, light and dark. The dark frames show each control's other state: the model picker open on the Briefing, and the rail sorted By feature on the Review.

Showing a flag in the file

A flag's note is written once, where the flag is anchored. Everywhere else is a pointer.
  • File header: a pointer with kind and line, such as deviation, line 14 ↓. Clicking it scrolls to the note. The header never repeats the note.
  • The flagged line: carries the note and + Comment, and the flagged code itself gets a pink mark, so the line stays marked after you scroll past the note.
  • No line to anchor to: the header is the anchor, so it carries the note (cancel.ts below).
  • Collapsed file: the header is all that's on screen, so it carries the note until you expand (types/appointment.ts).

The directions show this rule three ways: Print puts the note in a margin beside its line, Tool puts a compact row directly under the line, and Checklist puts a full-width row above it.
