The colorway set

Three colorways, decided: Hazard is the default, with Riso and Scope as alternatives. Each has its own flag color (hi-vis yellow, fluoro pink, Mantis green) and ships in light and dark. Each shows the same piece of the Review screen in light and dark, with the type held constant so only color varies.

How several colorways would work

The viewer never names a color. Every screen uses roles: flag, accent, the four verdicts, added and removed, the tier ramp. A colorway is one set of values for those roles, in light and dark. Switching swaps the set; drafts, reviewed marks and layout don't move. The pick is remembered on this machine, and light or dark still follows the system inside whichever colorway you're in.

What every colorway has to do

A flag is the loudest thing in the diff. The four verdicts read as a scale from "stop" to "done". Added and removed lines differ without reading the + and −. And the accent can't be the flag color, or every button looks like a warning. A new colorway is valid when it fills every role below and passes those four checks.
